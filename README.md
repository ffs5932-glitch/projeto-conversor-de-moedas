# 💱 Conversor de Moedas

> Conversão simples e rápida entre Dólar, Real Brasileiro, Euro, Libra Esterlina e Bitcoin.

---

## 📖 Sobre
Projeto criado para praticar desenvolvimento web, com conversão automática entre as principais moedas. Basta escolher a moeda, digitar o valor e o resultado aparece na hora.

---

## 🚀 Funcionalidades
- ✅ Conversão entre **BRL, USD, EUR, GBP e BTC**
- ✅ Atualização automática ao digitar ou trocar moeda
- ✅ Interface simples e fácil de usar
- ✅ Responsivo — funciona no celular e no computador

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** — Estrutura da página
- **CSS3** — Estilo e aparência
- **JavaScript** — Lógica de conversão

---

## ▶️ Como Usar
1. Baixe ou clone este repositório
2. Abra o arquivo **`index.html`** diretamente no navegador
3. Selecione a moeda de origem
4. Digite o valor que deseja converter
5. Os resultados aparecem automaticamente! 🎉
